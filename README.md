# Professional Website

This repository is fully autonomous: it incrementally builds a beautiful, professional website over 60 days, with exactly 3 real commits per day, using a cloud-based bot and CI.

- Light & dark mode
- Calm, professional, accessible design
- No manual steps required after setup
- All backend logic is efficient and self-auditing

## Local Development

```
npm install
npm run dev
```
